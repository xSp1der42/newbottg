# Куда кидать баннеры

## Одна папка на бренд, отдельный файл на площадку

```
banners/
  playerok/
    tiktok.mp4    ← TikTok
    insta.mp4     ← Instagram Reels
    shorts.mp4    ← YouTube Shorts
```

Имя файла должно **точно совпадать** с кодом площадки: `tiktok`, `insta`, `shorts`.
Расширение — только `.mp4` (плюс `.webm` / `.mkv`, если очень нужно).

Если файла под площадку нет, бот возьмёт `media` из `configs/brands/<бренд>.json`.

## Хромакей

Сейчас фон вырезается **автоматически**: бот смотрит рамку кадра и определяет цвет
хромакея. Проверено на твоих баннерах:

| файл     | что за фон      | цвет       |
|----------|-----------------|------------|
| tiktok   | тёмно-зелёный   | `#274502`  |
| shorts   | тёмно-зелёный   | `#274502`  |
| insta    | пурпурный       | `#510054`  |

Цвет вручную задавать не нужно. Если хочешь зафиксировать — в
`configs/brands/playerok.json`:

```json
"chroma_key": {
  "color": "0x274502",
  "similarity": 0.06,
  "blend": 0.02
}
```

`"color": "auto"` — определить автоматически (по умолчанию).

### Не завышай `similarity` / `blend`

Замеры на реальных баннерах (по альфа-каналу):

| similarity | blend | фон вырезан | контент убит |
|-----------|-------|-------------|--------------|
| 0.04      | 0.00  | 99.4%       | 0.00%        |
| **0.06**  | **0.02** | **99.6%** | **0.00%**    |
| 0.10      | 0.05  | 99.9%       | 0.01–0.22%   |
| 0.15      | 0.06  | 100%        | 1.2–2.7% ⚠️  |
| 0.30      | 0.10  | 100%        | 14–15% ⚠️    |

Дальше 0.10 ключ начинает **выжигать сам баннер**. Норма — 0.06 / 0.02.

## Как выглядит баннер

- 16:9 или около того (горизонтальный). Твои tiktok/shorts — 1440x600, нормально.
- Фон однотонный, без градиента и шума — иначе автоопределение не сработает.
- Не давай рамке кадра содержать контент: бот считает рамку фоном.

## Что будет с площадью

ТЗ требует ≥ 1/6 экрана (16.7%). На 1080x1920:

- `insta.mp4` (2000x1920, почти квадрат) → **30% экрана** ✅
- `tiktok.mp4` / `shorts.mp4` (1440x600, слишком вытянутые) → **14% экрана** ⚠️

Для tiktok/shorts баннер физически не дотягивает до 1/6 при сохранении
пропорций. Варианты: сделать баннеры менее вытянутыми (например 1080x900),
либо принять 14%. Бот честно предупредит в подписи к видео.

## Рендер

```bash
python render.py input.mp4 playerok tiktok output.mp4
```

Кадр 1080x1920, safe zones из `configs/platforms.json` (это зоны рекламы,
не органики — контент под ними перекрывается интерфейсом).

## Активировать бренд

`configs/brands.json` — список активных брендов. Сейчас там только `playerok`:

```json
{ "active": ["playerok"] }
```

Добавить остальные (1win, funpay, mostbet, mycsgo) — допиши их имена.
